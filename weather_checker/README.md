# Weather Alert System with Twilio WhatsApp Integration ☔📱


Projekt pobiera 18-godzinną prognozę pogody i wysyła alerty na WhatsApp przy użyciu Twilio.

## 🛠 Wymagania
- Python 3.8+
- Biblioteki: `requests`, `twilio`, `python-dotenv`  
  (zainstaluj je przez `pip install -r requirements.txt`)
